## 先看哪篇

| 你想知道 | 看这篇 |
|---|---|
| 深度在这批模型里到底被用成了什么 | `02-Multi-YOLO-RGB.md` |
| 没有深度相机行不行 | `03-YOLO26-自生成深度对比.md` |
| 换个部位（腹部）结论还成立吗 | `04-腹部实验-全部实验记录.md` |
| **4 通道变好，真的是深度的功劳吗** | `05-手心实验-全部实验记录.md` |
| 「第 4 通道」「深度的权重」是什么样子 | `深度通道图册.md` |

## 四篇的关系

```
深度通道图册（先建立直观印象）
      │
      ▼
02 手背：深度只被当成"整体亮度"，方向还反了
      │   ├──▶ 03 手背：换成 26 生成的深度会怎样
      │   ├──▶ 04 腹部：换部位后同样的结论成立吗（用"方向"）
      │   └──▶ 05 手心：4 通道的收益其实与深度无关
      ▼
结论：三部位的深度用法各不相同，各有专章
```
